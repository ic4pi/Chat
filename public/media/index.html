Media

Image · Video

Recommended: fal · FLUX (images) and fal · LTX / Wan (video) — they return URLs and avoid Vercel’s 4.5MB HTTP 413 limit on base64. Cloudflare FLUX/SDXL is still available and auto-falls back to fal when the image is too large. Keys in Vercel → Settings → Environment Variables: FAL_KEY (images + video), CLOUDFLARE_ACCOUNT_ID (32-char hex) + CLOUDFLARE_API_TOKEN (optional).
